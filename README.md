# HealthGuide AI

A Python-first healthcare information chatbot built with FastAPI, SQLite, JWT authentication, and the Groq API.

This application provides general health information only. It is not a diagnostic tool and must not be used for emergencies.

## Quick start

1. Create and activate a virtual environment.
2. Install `backend/requirements.txt`.
3. Copy `.env.example` to `.env` and add your keys.
4. Run `uvicorn app.main:app --reload` from the `backend` directory.
5. Visit `http://127.0.0.1:8000`.

See the project walkthrough in the chat instructions for the complete setup and deployment process.
